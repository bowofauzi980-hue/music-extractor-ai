# Kids Animation Studio AI

Studio perencanaan animasi anak 3D.

## Fitur

- Membuat konsep episode.
- Menyusun storyboard otomatis.
- Mengatur durasi video 3 sampai 5 menit.
- Mengatur karakter dan tujuan edukasi.
- Persetujuan sebelum tahap produksi.
- Download proyek dalam format JSON.

## Teknologi

- Python
- Gradio
- Hugging Face Spaces
- GitHub

## Menjalankan aplikasi

```bash
pip install -r requirements.txt
python app.py
```

## Pengembangan berikutnya

- AI Story Generator
- Character Studio 3D
- AI Voice Generator
- Lip Sync
- Blender Animation Engine
- Automatic Video Rendering
